# Handoff - 作業引き継ぎ資料の作成

ユーザーが作業名を指定した場合はそれを使い、省略した場合は現在の作業内容から適切なタイトルを自動生成してください。

## 手順

1. 現在の作業状況を把握する
   - `git branch --show-current` でブランチ名を取得
   - `git diff --stat` と `git status` で変更状況を確認
   - 直近の会話の流れから作業内容を把握

2. 引き継ぎ資料を作成する（2,000文字以内を目安）

   以下のセクションを含めること：

   | セクション | 内容 |
   |-----------|------|
   | Goal/Scope | 何を実施し、何を実施しないか |
   | Key decisions | 採用した方針とその理由 |
   | Done | 完了したタスク |
   | Pending | 未完了のタスク |
   | Next actions | 優先順位付きの次ステップ（3〜7個） |
   | Affected files | 変更・関連ファイルのパスと概要 |
   | Commands | ビルド・テスト・起動等の実行手順 |
   | Risks/Unknowns | 既知の問題やリスク |

   **重要**: 大きなコードブロックは貼り付けない。ファイルパスと行番号で示すこと。

3. ファイルに保存する

   - タイムスタンプを `YYYYMMDD-HHmm` 形式で生成
   - `docs/handoffs/` ディレクトリがなければ作成
   - `docs/handoffs/handoff-{timestamp}-{branch}-{title}.md` に保存
     - `{title}` は作業名をケバブケースに変換（省略時は `auto` ）
   - `docs/handoffs/_latest.txt` に保存したファイル名を書き込み
   - `CURRENT_WORK.md` の先頭に見出しと要約を追記（ファイルがなければ新規作成）

4. 完了メッセージ
   - 保存先パスを表示
   - 「新しいセッションで『引き継ぎ読み込んで』と伝えてください」と案内
