# Rehydrate - 引き継ぎ資料からの作業復旧

ユーザーが作業名やファイル名を指定した場合はそれを使い、省略した場合は最新の引き継ぎ資料を読み込みます。

## 手順

1. 引き継ぎ資料を特定する

   - ユーザーが名前を指定した場合: `docs/handoffs/` 内で名前に一致するファイルを検索
   - 省略した場合: `docs/handoffs/_latest.txt` を読み、記載されたファイルを使用
   - どちらも見つからない場合: `CURRENT_WORK.md` を読み込む

2. 引き継ぎ資料を読み込む

   - ファイルの内容を全て読み取る
   - Affected files セクションに記載されたファイルも確認する

3. 作業状況を把握・報告する

   以下を簡潔にまとめてユーザーに伝える：
   - 前回の作業で何が完了しているか
   - 未完了のタスクは何か
   - 推奨する次のアクション

4. 指示を待つ

   - 復旧内容を報告した後、ユーザーの指示を待つ
   - 勝手に作業を開始しない
